[[delete-a-data-collector]]
=== Elimina un raccoglitore di dati

Ransomware Resilience ora supporta l'eliminazione di un data collector. Il data collector viene creato automaticamente quando abiliti il rilevamento dell'attività utente sui workload; se il data collector diventa obsoleto, ora puoi eliminarlo manualmente.

Per ulteriori informazioni, vedi link:https://docs.netapp.com/us-en/data-services-ransomware-resilience/suspicious-user-activity.html#delete-a-data-collector["Elimina un raccoglitore di dati"^].
